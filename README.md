# Smile Coffee

Concept website for a fictional artisan coffee shop, built as if for a real client. Five pages (home, menu, gallery, about, contact) in French and English.

Live: **[smilecoffee.vercel.app](https://smilecoffee.vercel.app)**

## Features

- French and English with next-intl: language switcher and one URL per language
- Menu with a tab per category, photo gallery with a lightbox
- Animations with Motion that turn off when the visitor asks for reduced motion
- Skip link to jump straight to the content
- SEO: metadata, sitemap and robots
- Static site: no back end, no database

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, shadcn/ui, next-intl, Motion, Embla Carousel. Hosted on Vercel.

## Run locally

```bash
pnpm install
pnpm dev
```
